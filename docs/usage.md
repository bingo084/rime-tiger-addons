# 虎整辅助功能使用

已合并小鹤反查、zqj统计、反查时自动显示的拆分，以及始终开启的Emoji候选。D89-r3核心、弱纠错、提前上屏、个人快捷键及飞单配置保留。

## 小鹤双拼反查

先输入反引号，再打小鹤双拼：`nihc → 你好（jx bh）。前缀必须先按，单引号仍用于虎码选重。
空格确认；Ctrl+n/Ctrl+p 翻页。反查注释中的码来自当前虎整码表。

## 标点与特殊符号

- 空闲时单按分号 ;，立即输出「；」。
- 反斜杠 \ 直接输出顿号「、」，整句编码后也可以直接按。
- 未上屏的虎码编码中，分号仍是原方案的选重后缀；需要分号标点时先按空格上屏，再按 ;。
- 逗号、句号、问号等直接使用原标点键。
- 特殊符号：/sx 数学、/jt 箭头、/1 数字形式等；用 Ctrl+n/Ctrl+p 翻页。

## 统计

- /rtj：今天
- /ztj：近七日
- /ytj：近三十日
- /ntj：近365日
- /tj：累计
- /tjql：清空统计

统计汉字与中文标点，不含ASCII。记录字数、上屏次数、速度、平均码长、击键和连打率；包含提前上屏。
查询时显示仪表盘候选，Esc退出；按空格会把仪表盘插入当前应用。
本地数据目录：lua/zqj_stats.userdb。未导入隔离测试的数据。

## 拆分与 Emoji

- 拆分仅在小鹤反查时自动显示；正常打字不显示拆分。
- Emoji始终开启，正常打字和小鹤反查都自动提供匹配的Emoji候选。两项均无需快捷键或菜单开关。
- 拆分示例：小鹤反查你好，保留 jx bh，并追加〔亻⺈小·jxyx〕〔女子·bhi〕。
- 小鹤反查你好（反引号后输入 nihc），对应文字候选后追加👋、🙂等；选中后空格确认，候选较多时翻页。
- 正常输入你好（jxbh），Emoji追加在文字候选末尾，保留虎整Tab选词锁定所需的候选位置。
- 文字候选之间的顺序保留。手动选中的Emoji在继续输入或用标点确认时会提交。

文中的 Ctrl+n/Ctrl+p 来自个人 custom；本仓库的辅助模板不设置个人快捷键。
