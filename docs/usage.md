# 虎整辅助功能使用

已合并小鹤反查、zqj统计、反查时自动显示的拆分，以及始终开启的Emoji候选、独立个人词库。1.6.20261010.1 核心、弱纠错、提前上屏、个人快捷键及飞单配置保留。

## 小鹤双拼反查

先输入反引号，再打小鹤双拼：`nihc → 你好（jx bh）。前缀必须先按，单引号仍用于虎码选重。
空格确认；Ctrl+n/Ctrl+p 翻页。反查注释中的码来自当前虎整码表。

## 标点与特殊符号

- 空闲时单按分号 ;，立即输出「；」。
- 正斜杠 / 和反斜杠 \ 都直接输出顿号「、」，整句编码后也可以直接按。
- 未上屏的虎码编码中，分号仍是原方案的选重后缀；需要分号标点时先按空格上屏，再按 ;。
- 逗号、句号、问号等直接使用原标点键。
- <、>、$、= 等沿用官方标点映射；不再提供额外符号查询或轮换。

## 统计

先结束当前输入，再按 F4 或 Ctrl+反引号打开方案菜单。默认菜单会折叠选项，
先选中“中／。／半／…”这一行展开，再选择“查看统计”。

打开后默认显示今日仪表盘；h/k/← 切换到上一周期，j/l/→ 切换到下一周期。
周期依次为今日、七日、三十日、近365日、累计，循环切换。
Esc、空格或回车关闭；直接输入其他编码键也会关闭统计并继续打字；h/j/k/l 在统计打开期间用于切换。
查看及点击仪表盘不会把统计文本插入当前应用，也不会增加统计字数。
输入尚未结束时选择此项不会打开仪表盘，已有编码和 Tab 锁定保持原状。

统计汉字与中文标点，不含ASCII。记录字数、上屏次数、速度、平均码长、击键和连打率；包含提前上屏。
本地数据目录：lua/zqj_stats.userdb。原有统计数据保留，不再使用 /tj 等查询或清空指令。

## 拆分与 Emoji

- 拆分仅在小鹤反查时自动显示；正常打字不显示拆分。
- Emoji始终开启，正常打字和小鹤反查都自动提供匹配的Emoji候选。两项均无需快捷键或菜单开关。
- 拆分示例：小鹤反查你好，保留 jx bh，并追加〔亻⺈小·jxyx〕〔女子·bhi〕。
- 小鹤反查你好（反引号后输入 nihc），对应文字候选后追加👋、🙂等；选中后空格确认，候选较多时翻页。
- 正常输入你好（jxbh），Emoji追加在文字候选末尾，保留虎整Tab选词锁定所需的候选位置。
- 文字候选之间的顺序保留。手动选中的Emoji在继续输入或用标点确认时会提交。

文中的 Ctrl+n/Ctrl+p 来自个人 custom；本仓库的辅助模板不设置个人快捷键。

## 独立个人词库

在 Rime 用户目录创建 custom_phrase.txt，每行「词、编码、可选位置」，字段用 Tab 分隔：

```text
要不要	vcv
不要	cv
要不	vc
```

默认放在同码官方候选前面。需要放在官方候选后面时，在第三列写 after：

```text
不要	cv	after
```

同一位置内按文件行序排列；相同「词 + 编码」去重。第三列是 before/after，
不是数值权重。个人词能单独选用，也能按整句引擎的规则参与组词；
后置的非首选多字词参与组词时需要显式选重，例如 cv;sh → 不要说。
原有字不会因为个人词前置而丢失；最优码判定继续使用官方条目。

手动改完文件后重新部署并重载输入法。读取和合并只在词库加载时执行，
不会写回 tiger_sentence.codes.txt，也不会在日常打字时自动加词或改写个人文件。
官方升级覆盖核心后，再运行 scripts/install.py 恢复加载补丁。
个人词文件单独备份；本机由 chezmoi 管理，仓库安装脚本不会覆盖它。

## 整句自动选重（1010）

自动选重最低码数默认为 3：非首选单字需要自身匹配的编码达到三码，
才能省略选重键参与组句。二码仍可在完整候选中手选，也可用分号、引号或数字显式选重。
首选词条不受门槛影响；非首选多字词仍需要显式选重。

旧“允许单字重码组句”开关不再读取，也不会转换成新设置。
需要允许符合原规则的二码非首选单字自动参与组句时，在个人 custom 的 patch 中合并：

```yaml
  tiger_sentence/auto_select_min_code_length: 2
```

默认值为 3，0 禁用自动选重，范围 0～128。修改后重新部署并重启输入法。

## 自学习记录（1010）

人工改选正码并成功提交时，按分差提升 1～3 级，最多 10 级；普通首选和自动上屏不强化。
学习实际输入编码和所选正码片段，学习分参与解码，足够时可超过纠错候选。
独立选择两字词会学习整个词，可在不同前缀的句子中复用；较长句子的改选优先强化
无歧义的已确认局部片段。同码 Direct 候选保持码表名次，Direct 与组句候选按分数竞争。

学习记录在 Rime 用户目录的 自学习-tiger_sentence.txt，使用可读 UTF-8 文本。
它与 custom_phrase.txt（个人编码）和 tiger_sentence.supplement.txt（静态加权语料）分别维护。
1009 的普通片段记录继续生效；fusion-v1| 与 exact-correction-v1| 两类旧整句硬排序记录
会被忽略，不迁移，也不删除原始行。不读取、不迁移更早的学习数据库，旧文件保留。
学习文件应在完整退出输入法后编辑，再重启生效。
